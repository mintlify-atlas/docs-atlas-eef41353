JAZ ships `ainvoke` — the async counterpart to `invoke`. It accepts identical arguments, returns the same types, and works with all the same hooks and configuration overrides. The key difference is that `ainvoke` is a coroutine, enabling you to run multiple agents concurrently and to use `await` inside the agent's own REPL code.

## Basic usage

`ainvoke` has the same signature as `invoke`. Pass hooks positionally, provide inputs as keyword arguments, and `await` the result:

```python
import asyncio
import jaz
from jaz.hooks import ReturnType

async def main():
    result = await jaz.ainvoke(
        ReturnType(int),
        task="Calculate the factorial of 10",
    )
    print(result)

asyncio.run(main())
```

## Top-level await in the REPL

When an agent is invoked via `ainvoke`, its REPL runs in an async context that supports top-level `await`. This means the agent can call async functions directly in its generated code:

```python
import asyncio
import jaz
from jaz.hooks import ReturnType

async def fetch_data(url: str) -> dict:
    """Fetch JSON data from a URL asynchronously."""
    import aiohttp
    async with aiohttp.ClientSession() as session:
        async with session.get(url) as response:
            return await response.json()

async def main():
    result = await jaz.ainvoke(
        ReturnType(dict),
        task="Fetch the data from the given URL and summarize it",
        fetch_data=fetch_data,
        url="https://api.example.com/data",
    )
    return result

asyncio.run(main())
```

<Info>
`invoke` (the synchronous version) blocks the event loop when called from an async context. Always use `ainvoke` inside `async` functions to avoid blocking the event loop.
</Info>

## Running multiple agents concurrently

`asyncio.gather` lets you run several agents in parallel. Each agent gets its own invoke scope, and hooks activated with `with` propagate into all concurrently running agents:

```python
import asyncio
import jaz
from jaz.hooks import BudgetPool, ReturnType

async def analyze_item(item: str) -> str:
    return await jaz.ainvoke(
        ReturnType(str),
        task="Analyze this item and return a one-sentence summary",
        item=item,
    )

async def main():
    items = ["Report Q1", "Report Q2", "Report Q3"]

    # Run all three agents concurrently, sharing one cost budget
    with BudgetPool(cost_budget=2.00):
        results = await asyncio.gather(*[analyze_item(item) for item in items])

    for item, summary in zip(items, results):
        print(f"{item}: {summary}")

asyncio.run(main())
```

## Hooks and configuration work identically

`ReturnType`, `ConfigOverride`, `IterationLimit`, `BudgetPool`, and every other hook work exactly the same with `ainvoke` as they do with `invoke`:

```python
import asyncio
import jaz
from jaz.hooks import ReturnType, IterationLimit, FileLogger
from jaz.llm import LiteLLM

async def main():
    async with asyncio.TaskGroup() as tg:
        task_a = tg.create_task(
            jaz.ainvoke(
                ReturnType(list),
                jaz.ConfigOverride(llm=LiteLLM(model="openai/gpt-5-mini")),
                IterationLimit(max_iterations=10),
                task="Extract all named entities from this text",
                text="Alice met Bob at the Eiffel Tower in Paris.",
            )
        )
        task_b = tg.create_task(
            jaz.ainvoke(
                ReturnType(dict),
                task="Count the word frequencies in this passage",
                text="the cat sat on the mat the cat",
            )
        )

    print("Entities:", task_a.result())
    print("Frequencies:", task_b.result())

asyncio.run(main())
```

## Propagating hooks across async tasks

Hooks activated with `with` are stored in context variables. `asyncio.Task` copies the context at creation time, so hooks active when you create a task are visible inside it:

```python
import asyncio
import jaz
from jaz.hooks import BudgetPool, PrintLogger, ReturnType

async def run_agent(prompt: str) -> str:
    return await jaz.ainvoke(ReturnType(str), task=prompt)

async def main():
    # Both agents see PrintLogger and BudgetPool
    with PrintLogger(), BudgetPool(cost_budget=1.00):
        results = await asyncio.gather(
            run_agent("Summarize the history of Python"),
            run_agent("Explain asyncio in one paragraph"),
        )
    print(results)

asyncio.run(main())
```

<Note>
Raw `threading.Thread` does **not** inherit context variables. If you spawn worker threads, propagate the context manually with `contextvars.copy_context().run(...)`.
</Note>

## Complete working example

```python
import asyncio
import jaz
from jaz.hooks import BudgetPool, ReturnType

async def process_document(doc: str, index: int) -> dict:
    """Process a single document and return structured results."""
    return await jaz.ainvoke(
        ReturnType(dict),
        task="Extract the title, author, and main topics from this document",
        document=doc,
    )

async def main():
    documents = [
        "Python 3.13 Release Notes by the PSF...",
        "Introduction to asyncio by David Beazley...",
        "JAZ: An Agent Framework by the JAZ Team...",
    ]

    with BudgetPool(cost_budget=1.00):
        results = await asyncio.gather(
            *[process_document(doc, i) for i, doc in enumerate(documents)]
        )

    for i, result in enumerate(results):
        print(f"Document {i}: {result}")

if __name__ == "__main__":
    asyncio.run(main())
```
