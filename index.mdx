JAZ is a Python framework for building and running LLM agents. An agent gets a task, writes Python code in a REPL, observes results, and keeps iterating until the task is done — no orchestration boilerplate required. Pass tools as plain functions, control execution with composable hooks, and route to any LLM provider through LiteLLM.

## How JAZ Works

JAZ runs agents as a conversation between an LLM and a Python REPL. Each turn, the LLM generates code, the REPL executes it, and the result is fed back — repeating until the agent calls `return` with its answer.

<Steps>
  <Step title="Install JAZ">
    ```bash
    pip install jaz-lang
    ```
  </Step>
  <Step title="Set your API key">
    ```bash
    export OPENAI_API_KEY=sk-...
    ```
  </Step>
  <Step title="Run your first agent">
    ```python
    from jaz import invoke
    from jaz.hooks import ReturnType

    result = invoke(
        ReturnType(int),
        task="Calculate the factorial of 10",
    )
    print(result)  # 3628800
    ```
  </Step>
  <Step title="Add tools and data">
    ```python
    def web_search(query: str) -> list[str]:
        """Search the web and return result snippets."""
        ...

    result = invoke(
        ReturnType(dict),
        task="Look up each name and summarize what you find",
        names=["ada lovelace", "grace hopper"],
        web_search=web_search,
    )
    ```
  </Step>
</Steps>

## Key Features

<CardGroup cols={2}>
  <Card title="REPL-Based Agent Loop" icon="terminal">
    Agents write and execute real Python code, observe results, and iterate — no rigid DAGs or hand-wired chains.
  </Card>
  <Card title="Tools as Plain Functions" icon="function">
    Pass any Python function as a keyword argument. Its signature and docstring become the agent's description automatically.
  </Card>
  <Card title="Extensible Hook System" icon="plug">
    Observe and influence every stage of agent execution via typed events and effects — add logging, budget limits, tracing, and custom logic without modifying core code.
  </Card>
  <Card title="Any LLM Provider" icon="cloud">
    LiteLLM routes to OpenAI, Anthropic, Gemini, Bedrock, Vertex, and more. Local servers and custom backends are supported too.
  </Card>
  <Card title="Recursive Agent Composition" icon="sitemap">
    Agents can spawn nested agents with separate budgets. Scope, config, and hooks propagate automatically through the invocation tree.
  </Card>
  <Card title="Built-in Observability" icon="chart-line">
    Trajectory recording, Langfuse tracing, OpenTelemetry, Jaeger, and file/console loggers ship out of the box.
  </Card>
</CardGroup>
